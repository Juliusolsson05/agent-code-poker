♠ AGENT CODE POKER · PRIVATE LAN

Bring your friends to the table.

Six seats. Humans take an NPC’s seat at the next hand. Everyone plays from their own first-person view.

1. Start the host on your computer

In this game’s repository, run:

npm run build
npm run lan -- --lan

This explicitly enables private-LAN connections. Keep that terminal running. This page does not start a server or change your firewall.

If the port is already in use, preserve that session. Do not stop an old memory-only host unless everyone is finished—its table would be lost.

2. Open its lobby

Paste the host’s printed localhost URL below. On the next page, enter your name and choose Create table on this computer. Share its private-LAN URL and lobby code with friends.

Join on the same network

Ask your friend for the host’s private-LAN URL and lobby code. Paste the URL below—not localhost from their computer. On the next page enter your name and code, then choose Join table.

A code alone cannot find another computer. Public internet hosting and automatic discovery are not supported.

Use the exact address printed by the host. Never paste a seat key, password or lobby code here.

Practice chips only · Trusted LAN only

HTTP is unencrypted. Do not port-forward the host. The current 3D multiplayer build is still under end-to-end verification.

Your solo game remains in its original tab. Close this tab to return; opening this page does not replace its save.
